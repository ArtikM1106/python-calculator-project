Цель и актуальность
Создать настольный калькулятор для повседневных расчётов.
В одном окне можно быстро проверить ответ или вычислить величину по двум числам.

Задачи
1. Сравнить два существующих калькулятора и выбрать функции проекта.
2. Создать графическое окно и реализовать четыре арифметических действия.
3. Проверить расчёты, очистку и обработку деления на ноль.

Сравнение аналогов по официальной документации

Критерий               | Калькулятор Windows          | Калькулятор macOS
-----------------------|------------------------------|-----------------------------
Базовая арифметика     | Стандартный режим            | Основной режим
История вычислений     | Просмотр прошлых вычислений  | Просмотр и повторный вызов
Дополнительные режимы  | Научный, графический,        | Научный и программистский
                       | программистский, расчёт дат  |
Преобразование единиц  | Встроенные конвертеры        | Перевод единиц и валют

Вывод
Нашему приложению достаточно одного базового режима. На экране должны быть
цифры, десятичная точка, кнопки четырёх действий, очистки и получения результата.
Поле над числом показывает выбранное действие, выполненный расчёт или сообщение
об ошибке. История, дополнительные режимы и конвертеры выходят за рамки проекта.

Функциональные требования
• Вводить целые и дробные числа кнопками, с одной точкой в каждом числе.
• Складывать, вычитать, умножать и делить. Показывать результат по кнопке «=».
• Использовать результат для следующего действия. Цепочка считается по порядку ввода.
• Сбрасывать ввод и выбранное действие кнопкой C.
• При делении на ноль показывать «На ноль делить нельзя» и разрешать новый ввод.

Нефункциональные требования
• Одно графическое окно с читаемым результатом. Работа без интернета.
• Запуск на Python 3 с Tkinter. Код программы хранится в одном файле.
• Результат выводится с точностью до 12 значащих цифр.

Технологии
Python подходит для простой арифметики и обработки нажатий обычными функциями.
Tkinter входит в стандартную библиотеку Python и позволяет собрать окно с кнопками.

Запуск
В папке проекта выполните: python calculator.py
